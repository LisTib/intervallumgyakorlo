# Intervallumgyakorló

Interaktív gyakorlóoldal az intervallumok témához: zárt és nyílt intervallumok felírása, ábrázolása számegyenesen (tele / üres karika), átírás relációs jelekről intervallumra és vissza, valamint halmazműveletek intervallumokkal (unió, metszet, különbség) ábrázolással és felírással.

Megnyitás: `index.html` böngészőben, vagy GitHub Pages-en.
